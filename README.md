# 🚀 Task Management System API (Task_Manage)

A robust RESTful API backend for managing tasks, users, and automated email notifications, built with Laravel and MySQL.

---

## ✨ Features & Capabilities

- **Task & User Management:** Complete CRUD functionality for handling tasks, status updates, and user assignments.
- **RESTful API Architecture:** Standardized JSON request and response structure.
- **Automated Email Notifications (SMTP):** Integrated email service using Laravel Mailables to notify users regarding updates or actions.
- **Database Migrations & Eloquent ORM:** Structured MySQL database schema with relationships between users and tasks.
- **Request Validation:** Strict server-side validation to ensure data integrity and security.
- **Authentication & Security:** Protected routes and token-based access control.

---

## 🛠️ Tech Stack

- **Backend Framework:** Laravel (PHP)
- **Database:** MySQL
- **Email Protocol:** SMTP (Laravel Mailables)
- **API Testing:** Postman / Thunder Client
